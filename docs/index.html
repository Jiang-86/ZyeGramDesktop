ZyeGram v1.0

基于 AyuGram Desktop / Telegram Desktop，增加复读、关键词高亮、本地修改等功能。

下载 Windows x64 查看源码 官方频道

功能

  • 双击复读文字、图片、视频和媒体组。
  • 关键词高亮和关键词通知。
  • 本地修改文字、表情显示。
  • 禁用官方 AyuGram 自动更新，避免覆盖 ZyeGram。
